# LOTR хадмал орчуулгын заавар

## Зорилго ба хэрэглэх арга

Энэ заавар нь "The Fellowship of the Ring (2001) Extended", "The Two Towers (2002) Extended" ба "The Return of the King (2003) Extended" киноны эцсийн Монгол хадмал дээр тогтсон нэр томьёо, бүтэц, дүрмийг нэгтгэсэн. Бусад ангийг орчуулж, шалгахад энэ стандартаар явна.

Шинэ session эхлүүлэхдээ:

1. Энэ баримтыг (эсвэл түүний Markdown экспортыг) хавсаргана.
2. Тухайн ангийн Англи .srt файлыг хавсаргана. Боломжтой бол idx/sub эх зураг, мөн албан ёсны Англи .srt-г нэмнэ.
3. Дараах маягаар даалгавар өгнө:

> Хавсаргасан "LOTR хадмал орчуулгын заавар"-ыг дүрэм болгон баримтал. Англи .srt-г мөр, дугаар, цагийг нь өөрчлөхгүйгээр Монгол руу орчуул. Нэр томьёоны толинд байгаа үгийг яг тэр хэлбэрээр нь хэрэглэ. Толинд байхгүй шинэ нэрийг тусад нь жагсааж, миний баталгаажуулалтад өг.

Дүрэм хоорондоо зөрчилдвөл эрэмбэ нь: (1) Англи файлын бичвэр, хэлбэр; (2) энэ баримтын нэр томьёоны толь; (3) бусад хэв маягийн дүрэм.

## Файлын бүтэц

Монгол файл нь Англи файлтай мөр бүрээр 1:1 таарна: дугаар, цаг, мөрийн тоо ижил.

| Зүйл | Дүрэм |
| --- | --- |
| Файлын нэр | Англи файлын нэр + `.mn.srt` |
| Кодлол | UTF-8, BOM-гүй |
| Мөр таслалт | CRLF (Windows) |
| Дугаар, цаг | Англи файлаас яг хуулна, өөрчлөхгүй |
| Мөр доторх мөрийн тоо | 1 эсвэл 2 (3 мөр хэрэглэхгүй) |

## Налуу, цэг тэмдэг, том үсэг

Ерөнхий зарчим: Англи файлд байгаа тэмдэг бүр Монголд ижил байрандаа байна, байхгүйг нэмэхгүй.

**Налуу `<i>`**

- Англи файлд налуу бол Монголд ч налуу: өгүүлэгчийн яриа, дэлгэцийн гаднах дуу хоолой, дууны үг, дурсамж, уншиж буй бичиг.
- Мөр бүрийг тусад нь хаана (`<i>...</i>` мөр тус бүрт). Англид хоёр мөр дамжсан нэг тагтай бол тэр хэлбэрийг дагана.
- Хэсэгчлэн налуу (нэг үг, нэг мөр) байвал тухайн хэсгийг л налуу болгоно: `<i>-Чадвал би түүнийг дагах ёстой</i>` / `-Та хоцорчээ.`
- Дууны мөрөнд Англид цэг тэмдэг байхгүй бол Монголд ч тавихгүй.

**Цэг тэмдэг**

| Тэмдэг | Хэрэглээ |
| --- | --- |
| `...` | Өгүүлбэр дараагийн мөрт үргэлжилж байвал төгсгөлд нь `...`, дараагийн мөрийн эхэнд `...` — Англи файлын дагуу |
| `....` | Зөвхөн Англи файлд дөрвөн цэг байгаа газар (жишээ: `Аан, тийм....`). Бусад газар гурав цэг |
| `--` | Яриа тасарсан, бусдад таслуулсан (`Би, аан--`, `-Ноён Фродо--`). Англид байгаа газарт л |
| `"..."` | Хоёр давхар шууд хашилт: ишлэл, ном унших, бичээс. Тасралтай ишлэлийн эхлэл төгсгөл Англитай адил мөрөнд |
| `?!` | Англид байвал хэвээр |
| Тоо | Араб тоогоор: `111 нас`, `1296 оных`, `22-ны өдөр`, `10,000 цэрэг`, `20 миль`. Дууны "miles" → "бээр" |
| Зай | `-` зураасны ард зай байхгүй; цэг тэмдгийн өмнө зай байхгүй |

**Том үсэг**

- Англи файлд том үсгээр эхэлсэн үг бүрийн Монгол харгалзаа том үсгээр эхэлнэ: Hobbit → Хоббит, Elves → Эльфүүд, Orcs → Оркууд, Men (арьстан) → Хүмүүс / Хүн төрөлхтөн.
- Англид жижиг бол Монголд ч жижиг: wizard → шидтэн, halfling → хагас биетэн, goblins → гоблин, mithril → митрил, dragon → луу (өгүүлбэрийн эхэн бол мэдээж том).
- Олон үгтэй нэрд Англид том үсгээр эхэлсэн үг бүрийн харгалзааг томоор: Mount Doom → Сүйрлийн Уул, Dark Lord → Харанхуйн Эзэн, Free Peoples → Чөлөөт Ард түмнүүд, Westfarthing → Баруун хязгаар (нэг үг тул эхнийх нь л том).
- Англи ахмад цол Монголд нэрийн өмнө байвал том: Mr. Frodo → Ноён Фродо, Lord Celeborn → Ноён Келеборн. Нэрийн ард орвол жижиг: Master Elrond → Элронд эзэнтэн. "my lord" → "эзэнтэн минь".

## Хэв маяг ба хэллэг

**Хаяглалт (Та / чи)**

| Хэн → хэнд | Хэлбэр | Жишээ |
| --- | --- | --- |
| Сэм → Фродо | Та + "Ноён Фродо" | Танд жаахныг үлдээсэн шүү, Ноён Фродо. |
| Хоббитууд → Гэндальф | Та | Тантай уулзах үнэхээр сайхан байна, Гэндальф! |
| Гэндальф → хоббитууд, Бильбо | чи | Чи ганц ч хоногоор хөгшрөөгүй байна. |
| Гимли → Леголас (ёжтой) | та + "Эльф Ноёнтон" | Удахгүй, Эльф Ноёнтон, та... |
| Дарамтаас эзэнд | "эзэнтэн минь" | Мэлмий юу тушаав? |
| Олон хүнд | та нар | Та нар ойлгохгүй байна уу? |

**Ярианы өнгө аяс**

- Өгүүлэгчийн домгийн яриа нь өнгөрсөн цагийн -жээ/-чээ, -в/-лаа хэлбэртэй, хуучин сонгодог үгстэй: "давтжээ", "хийгээд", "өгөгдсөн ажээ".
- Хоббитуудын яриа халуун, ардын хэллэгтэй: "Тулгая", "Чөтгөр ав гэж", "Тукийн тэнэг ээ!".
- Голлум: "Эрдэнэ минь", богино, давталтай өгүүлбэр: "Минийх. Миний хайр. Минийх."
- Аялга үгийг Англитай ижил байранд нь хадгална: Oh → Өө, Ah → Аа, Um/Uh → Аан, Hm → Мм, Hey → Хөөе, Whoa/Wow → Хөөх, eh → айн.
- Хоёр дахь хэллэг ("миль", "бээр") ба нэгжийг Англи файлын утгаар нь үлдээнэ, хөрвүүлэхгүй.

**Нэрийг гадаад хэлнээс буулгах зарчим**

- Эльф, газрын нэрийг дуудлагаар нь: th → т (Араторн, Эктелион), dh → д (Галадрим, Карадрас), û/ú → ү (Барад-дүр, Назгүл, Амон Сүл), ie → иэ (Галадриэль, Лүтиэн, Лотлориэн), ä → а (Эарендил), é → е (Смеагол).
- Англи хоббит нэрийг Англи дуудлагаар: a → э (Бэггинс, Гэмжи, Сэм, Гэндальф), ace → эйс (Брэйсгэрдл).
- Утгатай нэр, цолыг орчуулна: Prancing Pony → Цовхрох Пони, Sting → Хатгуур, Misty Mountains → Манант Уулс. Гэхдээ хэрэглэгчийн шийдвэрээр оноосон нэр болгосон зүйлс бий: Strider → Страйдер, Underhill → Андерхилл, Bag End → Бэг Энд.
- Нэрийн ард тийн ялгаварыг шууд залгана: Бөгжийг, Шайрт, Сауронд, Барад-дүрийн, Исилдураас. Арьстны олон тоо — -ууд/-үүд, хүний бүлэгт "нар" (Урук-хай нар).
