# Бөгжний Эзэн — Монгол хадмал орчуулга

**The Lord of the Rings Extended Edition гурвалын бүрэн Монгол хадмал (.srt)**

Энэ репозиторид «Бөгжний Эзэн» гурвалын Extended хувилбарын Англи хадмалаас Монгол руу орчуулсан хадмал файлууд, мөн орчуулгыг нэг стандартаар хийхэд ашигласан **орчуулгын заавар** (нэр томьёоны толь, хэв маягийн дүрэм) багтсан. Орчуулга нь гурван киноны бүх ярианд нэр, газар, ойлголтыг ижил хэлбэрээр хэрэглэсэн.

> Видео файл энэ репозиторид байхгүй. Зөвхөн хадмал болон заавар.

## Аль хувилбарыг сонгох вэ

| Хувилбар | Юу агуулдаг вэ | Хэнд тохиромжтой |
| --- | --- | --- |
| `.mn.srt` (HI / SDH) | Яриа + дуу чимээний тэмдэглэгээ (`[ХААЛГА ТОГШИНО]`), ярьж буй хүний нэр (`ГЭНДАЛЬФ:`), Эльф хэлээр ярих үеийн тэмдэглэгээ | Сонсголын бэрхшээлтэй үзэгч, дуугүй үзэх үед |
| `.mn.nonHI.srt` | Зөвхөн яриа | Ихэнх үзэгч |

## Хэрхэн ашиглах

1. Хадмал файлыг видео файлтай нэг хавтсанд хийнэ.
2. Хадмалын нэрийг видео файлын нэртэй ижил болгоод ард нь `.mn.srt` гэж үлдээнэ. Жишээ нь:

   ```
   The Fellowship of the Ring.mkv
   The Fellowship of the Ring.mn.srt
   ```

3. VLC, mpv, MPC-HC, Kodi, Plex, Jellyfin зэрэг тоглуулагч ихэвчлэн автоматаар уншина. Уншихгүй бол тоглуулагчийн цэснээс хадмалыг гараар сонгоно.

Файлууд **UTF-8** кодлолтой. Хэрэв кирилл үсэг эвдэрч харагдвал тоглуулагчийн тохиргоонд хадмалын кодлолыг UTF-8 болгоно.

## Аль видеотой таарах вэ

Хадмалын цаг нь **Extended Edition** хувилбарын (4K UHD Blu-ray, 2160p) Англи хадмалын цагтай яг ижил. Тиймээс:

- **Extended** хувилбартай таарна.
- **Театрын (theatrical)** хувилбартай таарахгүй — үргэлжлэх хугацаа, үзэгдлүүд нь өөр.
- Өөр эх сурвалжтай (жишээ нь өөр кадрын давтамжтай) хувилбар дээр бага зэрэг хоцрох эсвэл түрүүлэх бол тоглуулагчийн хадмалын хоцролтын (subtitle delay) тохиргоог ашиглана.

## Орчуулгын заавар

Энэ заавар нь гурван киноны эцсийн Монгол хадмал дээр тогтсон нэр томьёо, бүтэц, дүрмийг нэгтгэсэн. Засвар оруулах, шинэ хувилбар гаргахдаа энэ стандартыг баримтална.

Дүрмүүд хоорондоо зөрчилдвөл эрэмбэ нь:

1. Англи эх файлын бичвэр, хэлбэр
2. [Нэр томьёоны толь](#5-нэр-томьёоны-толь)
3. Бусад хэв маягийн дүрэм

### 1. Файлын бүтэц

HI хувилбар (`.mn.srt`) нь Англи эх файлтай мөр бүрээр 1:1 таарна: дугаар, цаг, мөрийн тоо ижил.

| Зүйл | Дүрэм |
| --- | --- |
| Файлын нэр | Англи файлын нэр + `.mn.srt` (non-HI: `.mn.nonHI.srt`) |
| Кодлол | UTF-8, BOM-гүй |
| Мөр таслалт | CRLF (Windows) |
| Дугаар, цаг | HI хувилбарт Англи файлаас яг хуулна, өөрчлөхгүй |
| Нэг дэлгэцийн мөрийн тоо | 1 эсвэл 2 (3 мөр хэрэглэхгүй) |
| Мөрийн урт | Дундаж 40 тэмдэгт орчим, 45-аас хэтрэхгүйг хичээнэ (таг тооцохгүй) |
| Мөр хуваах | Утгаар нь хуваана. «ч», «нь», «руу», «гэж» зэрэг сул үгийг мөрийн эхэнд гаргахгүй |
| Хоёр хүний яриа | Англи файлтай адил, мөр бүр `-` зураасаар, зайгүй: `-Та хоцорчээ.` |

Англи файлд тасралтай (жишээ нь `...` гэж дуусаад дараагийн мөр `...` гэж эхэлсэн) өгүүлбэрийг Монголд ч мөн адил хоёр хэсэгт хуваана. Үгийн дарааллыг Монгол хэлний жамаар зохиож, хоёр хэсэг тус бүр утгатай байхаар бичнэ.

### 2. Hearing Impaired тэмдэглэгээ

Бүх HI тэмдэглэгээ Англи файлтай адил ТОМ ҮСГЭЭР бичигдэнэ. Байрлал, налуу эсэх нь Англи файлтай яг ижил.

**Дуу авиа, дүрслэл `[...]`**

- Үйл хөдлөл → одоо цагийн -на/-нэ/-но хэлбэр: `[KNOCKING]` → `[ХААЛГА ТОГШИНО]`, `[LAUGHS]` → `[ИНЭЭНЭ]`
- Эзэнгүй дуу чимээ → «... ЧИМЭЭ»: `[FOOTSTEPS]` → `[АЛХАХ ЧИМЭЭ]`, `[RUSTLING]` → `[ШАРЖИГНАХ ЧИМЭЭ]`

### 3. non-HI хувилбар гаргах

non-HI хувилбарыг HI хувилбараас дараах дүрмээр гаргана:

1. Зөвхөн `[...]` тэмдэглэгээтэй мөрийг бүхэлд нь хасна. Яриатай нэг мөрт байвал зөвхөн тэмдэглэгээг хасна (`[АНГЛИ ХЭЛЭЭР]` / `Фродо.` → `Фродо.`).
2. Ярьж буй хүний нэрийг (label) хасна. Хоёр хүний ярианд label байсан мөрийг `-` зураасаар солино:

   ```
   ФРОДО: Бильбо!          →   -Бильбо!
   -Сайн уу, Фродо, хүү минь.   -Сайн уу, Фродо, хүү минь.
   ```

3. Зөвхөн label-тай, яриагүй мөрийг (`АРВЕН:`) хасна.
4. Зөвхөн аялга үгнээс бүрдсэн мөрийг хасна (`Өө!`, `Аа.`, `Хөөе, хөөе.`), өгүүлбэрийн эхэнд ирсэн сул аялга үгийг хасна (`Өө, тийм...` → `Тийм...`, `Аан, тийм....` → `Тийм....`). Утга агуулсан дуудлага, хариу үг (`Хөөе!`, `Аха.`) хэвээр үлдэнэ.
5. Label хассаны дараа мөрийн хуваалтыг уртын дүрмээр дахин тэнцвэржүүлж болно.
6. Дугаарыг 1-ээс эхлэн дахин дугаарлана. Цагийг өөрчлөхгүй.

### 4. Налуу, цэг тэмдэг, том үсэг

Ерөнхий зарчим: Англи файлд байгаа тэмдэг бүр Монголд ижил байрандаа байна, байхгүйг нэмэхгүй.

**Налуу `<i>`**

- Англи файлд налуу бол Монголд ч налуу: өгүүлэгчийн яриа, дэлгэцийн гаднах дуу хоолой, дууны үг, дурсамж, уншиж буй бичиг.
- Мөр бүрийг тусад нь хаана (`<i>...</i>` мөр тус бүрт). Англид хоёр мөр дамжсан нэг тагтай бол тэр хэлбэрийг дагана.
- Хэсэгчлэн налуу бол зөвхөн тухайн хэсгийг налуу болгоно:

  ```
  <i>-Чадвал би түүнийг дагах ёстой</i>
  -Та хоцорчээ.
  ```

- Дууны мөрөнд Англид цэг тэмдэг байхгүй бол Монголд ч тавихгүй.

**Цэг тэмдэг**

| Тэмдэг | Хэрэглээ |
| --- | --- |
| `...` | Өгүүлбэр дараагийн мөрт үргэлжилж байвал төгсгөлд нь `...`, дараагийн мөрийн эхэнд `...` — Англи файлын дагуу |
| `....` | Зөвхөн Англи файлд дөрвөн цэг байгаа газар (`Аан, тийм....`). Бусад газар гурван цэг |
| `--` | Яриа тасарсан, бусдад таслуулсан (`Би, аан--`, `-Ноён Фродо--`). Зөвхөн Англид байгаа газарт |
| `"..."` | Давхар шууд хашилт: ишлэл, ном унших, бичээс. Тасралтай ишлэлийн эхлэл, төгсгөл Англитай адил мөрөнд |
| `?!` | Англид байвал хэвээр |
| Тоо | Араб тоогоор: `111 нас`, `1296 оных`, `22-ны өдөр`, `10,000 цэрэг`, `20 миль`. Дууны «miles» → «бээр» |
| Зай | `-` зураасны ард зай байхгүй, цэг тэмдгийн өмнө зай байхгүй |

**Том үсэг**

- Англи файлд том үсгээр эхэлсэн үгийн Монгол харгалзаа том үсгээр эхэлнэ: Hobbit → Хоббит, Elves → Эльфүүд, Orcs → Оркууд, Men (арьстан) → Хүмүүс / Хүн төрөлхтөн.
- Англид жижиг бол Монголд ч жижиг: wizard → шидтэн, halfling → хагас биетэн, goblins → гоблин, mithril → митрил, dragon → луу (өгүүлбэрийн эхэнд бол мэдээж том).
- Олон үгтэй нэрд Англид том үсгээр эхэлсэн үг бүрийн харгалзааг томоор бичнэ: Mount Doom → Сүйрлийн Уул, Dark Lord → Харанхуйн Эзэн, Free Peoples → Чөлөөт Ард түмнүүд. Нэг үгтэй нэрд зөвхөн эхнийх нь том: Westfarthing → Баруун хязгаар.
- Цол нэрийн өмнө ирвэл том: Mr. Frodo → Ноён Фродо, Lord Celeborn → Ноён Келеборн. Нэрийн ард ирвэл жижиг: Master Elrond → Элронд эзэнтэн. «my lord» → «эзэнтэн минь».

### 6. Хэв маяг ба хэллэг

**Хаяглалт (Та / чи)**

| Хэн → хэнд | Хэлбэр | Жишээ |
| --- | --- | --- |
| Сэм → Фродо | Та + «Ноён Фродо» | Танд жаахныг үлдээсэн шүү, Ноён Фродо. |
| Хоббитууд → Гэндальф | Та | Тантай уулзах үнэхээр сайхан байна, Гэндальф! |
| Гэндальф → хоббитууд, Бильбо | чи | Чи ганц ч хоногоор хөгшрөөгүй байна. |
| Гимли → Леголас (ёжтой) | та + «Эльф Ноёнтон» | Удахгүй, Эльф Ноёнтон, та... |
| Доод тушаалтан → эзэн | «эзэнтэн минь» | Мэлмий юу тушаав? |
| Олон хүнд | та нар | Та нар ойлгохгүй байна уу? |

**Ярианы өнгө аяс**

- Өгүүлэгчийн домгийн яриа нь өнгөрсөн цагийн -жээ/-чээ, -в/-лаа хэлбэртэй, хуучны сонгодог үгстэй: «давтжээ», «хийгээд», «өгөгдсөн ажээ».
- Хоббитуудын яриа халуун дулаан, ардын хэллэгтэй: «Тулгая», «Чөтгөр ав гэж», «Тукийн тэнэг ээ!».
- Голлум: «Эрдэнэ минь», богино, давталттай өгүүлбэр: «Минийх. Миний хайр. Минийх.»
- Аялга үгийг Англитай ижил байранд нь хадгална: Oh → Өө, Ah → Аа, Um/Uh → Аан, Hm → Мм, Hey → Хөөе, Whoa/Wow → Хөөх, eh → айн.
- Хэмжих нэгжийг («миль», «лиг», дуунд «бээр») Англи эхийн утгаар нь үлдээнэ, хөрвүүлэхгүй.

### 7. Нэрийг гадаад хэлнээс буулгах зарчим

- Эльф, газрын нэрийг дуудлагаар нь: th → т (Араторн, Эктелион), dh → д (Галадрим, Карадрас), û/ú → ү (Барад-дүр, Назгүл, Амон Сүл), ie → иэ (Галадриэль, Лүтиэн, Лотлориэн), ä → а (Эарендил), é → е (Смеагол).
- Англи хоббит нэрийг Англи дуудлагаар: a → э (Бэггинс, Гэмжи, Сэм, Гэндальф), ace → эйс (Брэйсгэрдл).
- Утгатай нэр, цолыг орчуулна: Prancing Pony → Цовхрох Пони, Sting → Хатгуур, Misty Mountains → Манант Уулс. Харин зарим нэрийг оноосон нэр хэвээр үлдээсэн: Strider → Страйдер, Underhill → Андерхилл, Bag End → Бэг Энд.
- Нэрийн ард тийн ялгалыг шууд залгана: Бөгжийг, Шайрт, Сауронд, Барад-дүрийн, Исилдураас.
- Арьстны олон тоо -ууд/-үүд, хүмүүсийн бүлэгт «нар» (Урук-хай нар).
